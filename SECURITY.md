# Security and Public-Repository Hygiene

This is an academic network-simulation portfolio. It should not contain credentials or production secrets, but public-repository hygiene still matters.

## Intentionally omitted
- student identification numbers;
- raw course-submission PDF;
- private cloud or lab credentials, if any are recovered later;
- unrelated personal metadata from screenshots;
- unverifiable source artifacts presented as original work.

## If source files are recovered
Before publishing original `.cc`, `.py`, `.sh`, `.tr`, XML, or plotting artifacts:
1. check for usernames, home-directory paths, tokens, or embedded credentials;
2. preserve original authorship/provenance where possible;
3. avoid rewriting team code history as sole personal work;
4. document simulator/version dependencies;
5. separate raw generated output from curated portfolio evidence.

## Responsible interpretation
Simulation output is not a security or reliability guarantee. Results apply only to the retained experiment conditions and should not be used as production-network performance promises.
